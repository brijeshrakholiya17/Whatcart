# WhatBytes Frontend Assignment

A responsive product listing app built with Next.js, Tailwind CSS, and Zustand.

## Live Demo
https://whatbytes-frontend-assignment-rho.vercel.app/

## Tech Stack
- Next.js 15 (App Router)
- Tailwind CSS v4
- Zustand (cart state, persisted to localStorage)
- lucide-react (icons)

## Features
- Product listing with category, brand, and price filters
- URL-based filter state (shareable/bookmarkable links)
- Live search with debounce
- Product detail pages with dynamic routing
- Cart with quantity controls, persisted across sessions
